IPO Event Regression Analysis

첨부한 이벤트 스터디 식을 기준으로 각 IPO 사례의 관련 상장 peer 기업에 대해 정상수익률을 추정하고, 이벤트 기간의 AR과 CAR을 산출했다.

Regression Model

ri,t = αi + β1,i rmkt,t + β2,i rind,t + εi,t
ARi,t = ri,t - (α̂i + β̂1,i rmkt,t + β̂2,i rind,t)
CARi,[a,b] = Σ ARi,t, t ∈ [a,b]

추정기간은 IPO일 기준 -250거래일부터 -20거래일까지다. r_mkt는 KOSPI/KOSDAQ 수익률, r_ind는 같은 IPO 사례의 peer 평균 수익률을 사용했다. 개별 peer 분석 시 r_ind에는 해당 종목을 제외했다.

Hypothesis Test Summary

H0: 대형 IPO 이벤트시 주가 지수와 동일 peer 그룹들이 모두 하락한다. H1: 대형 IPO 이벤트시 주가 지수와 동일 peer 그룹들이 모두 상승한다.
